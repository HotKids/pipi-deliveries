# Pipi Deliveries（派派助手 Lite）

Pipi Deliveries 是一款面向 Android 平台的快递管理应用，采用 Material 3 设计规范，并支持深色模式与系统动态配色。

## 功能简介

- 绑定手机号码，同步与其关联的菜鸟快递信息；部分京东购物订单也可能被同步，实际结果取决于上游服务返回；
- 输入运单号码即可识别承运商并查询物流动态；部分承运商可能需要验证收寄件手机号码后四位；
- 菜鸟快递使用适配后的详情页面，其他快递使用原生物流轨迹页面；
- 支持下拉刷新、后台同步与物流状态变更通知；
- 提供 2 × 2 状态概览和 4 × 2 物流动态两种桌面小组件，可直接查看快递详情或发起查询；
- 承运商图标均保存在本地，并支持深色模式与系统动态配色。

## 使用说明

在首页输入运单号码后即可发起查询。查询到有效物流轨迹时，应用将首先打开全屏详情页面；关闭详情页面后，该运单将被加入快递列表。尚未产生物流轨迹的运单会进入后台查询队列，并在出现首条物流动态后自动显示。

点击首页右上角的电话图标可管理已绑定的手机号码；在首页下拉可刷新快递信息。

已取消运单将在列表中保留四小时，已签收运单保留七日；期满后，相关运单及本地物流轨迹缓存将自动清理。删除已绑定的手机号码时，与该号码关联的快递信息亦会同时删除。

## 隐私说明

为提供手机号码绑定、验证码、快递同步及物流查询功能，应用会将完成请求所必需的手机号码、验证码、运单号码、手机号码后四位、随机生成的设备标识及网络信息，经由 Cloudflare Worker 中转至相关第三方服务。对于仅返回订单编号的记录，应用可能在本地加载第三方详情页面，以提取与订单对应的承运商运单号码；提取的运单号码会用于上述物流查询，并仅在本地持久化，已有运单号码时不再加载该页面。Worker 按当前设计不持久化保存上述业务数据；快递列表与物流缓存仅保存在用户的本地设备中。第三方页面可能在设备本地保存 Cookie 或其他网站数据；Cloudflare 及相关服务提供方也可能依据各自政策处理必要的网络日志、Cookie 或其他请求信息。

本项目的部分功能依赖通过逆向分析获得的第三方接口，其原服务提供方现已停止运营。因此，相关接口不具备长期可用性保障，并可能在未经通知的情况下停止服务；届时，依赖相关接口的功能可能无法继续使用。
