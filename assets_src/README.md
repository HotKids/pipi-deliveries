# Launcher artwork

`launcher_foreground.png` preserves the approved parcel foreground with `Pipi` on
the right label. Its 432 px canvas is the existing foreground canvas; density
variants use 108, 162, 216, 324 and 432 px for mdpi through xxxhdpi. Do not infer a
new label position or type size from a smaller density variant.

`launcher_512.png` retains the original parcel artwork before the label was added.
