# Repository boundary

- This repository is the only workspace for Pipi Deliveries work.
- Never read, write, inspect, compare, build, test, or run commands in the sibling `aicy-deliveries` repository.
- Never use `aicy-deliveries` as the working directory, even for read-only discovery.
- If an environment starts in `aicy-deliveries`, stop before running a command and switch to this repository root.
- Do not copy code or artifacts to or from `aicy-deliveries`.
